## Минимальная реальная проверка при любом варианте

1. На обычном бесплатном аккаунте в заявленном браузерном маршруте создать нейтральную картинку с кругом и треугольником; записать дату, ОС, тип устройства, браузер и факт бесплатного доступа, не сохраняя личные данные.
2. Скачать картинку на устройство, открыть **сохранённый локальный файл** и удостовериться, что он содержит исходник. Проверить, что формат файла пригоден для обратной загрузки (документация: JPEG/PNG до 20 МБ).
3. Повторно прикрепить **этот** файл через актуальное действие интерфейса; попросить добавить небольшую звезду. При необходимости использовать фактически доступный режим **редактирования изображения**, а не команду «нарисовать заново».
4. Проверить, что исходные фигуры остались узнаваемы и добавлена звезда; при неудаче не выдавать новую генерацию за редактирование.
5. Скачать изменённую версию под отдельным именем, открыть **оба локальных файла** и сравнить. Не полагаться только на историю чата.
6. Зафиксировать последовательность по шагам с наблюдаемыми результатами, дату и среду. При отличии телефона от компьютера проверить предусмотренный мобильный маршрут отдельно. Если функциональность не прошла без платной услуги, блокировка сохраняется, требуется пересмотр учебного сервиса/маршрута.
7. Только затем определить по наблюдаемым трудностям, нужны ли скриншоты для ученика. Подлинные обезличенные изображения возможны, выдуманный UI запрещён.

**Самостоятельно агент может:** проверить GitHub и справку, сопоставить текст со стандартом, подготовить критерии, затем при одобрении обновить документы/тесты через PR и выполнить положенные ролевые аудиты.

**Нужно участие человека:** утвердить вариант приёмки; провести или предоставить доказанный живой прогон на реально доступном бесплатном аккаунте/устройстве (здесь такой сеанс не проводился). До согласования текущие требования PR №212 остаются действующими.

**Другие ограничения:** EX-001 сохраняется; Stepik не синхронизировать. Обязательный gate ручного форматирования описания Stepik остаётся на финальный этап, **сейчас ничего не запрашивать у владельца**.
