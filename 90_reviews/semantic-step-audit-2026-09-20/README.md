## Как читать снимки

`rendered/Mxx-Lxx.json` содержит ученический текст в поле `html`; это результат штатной сборки, включая встроенные материалы по локальным ссылкам. `plan_row`, `source_git_paths`, `source_chunk_indexes` и прочие служебные поля — доказательная привязка для аудитора, а не текст экрана.

`semantic_audit_status: NOT_REVIEWED` в исходных снимках отражает момент восстановления. Актуальный прогресс, типы, оценки и исправления хранятся отдельно в `step-inventory.json`, а написанные вручную заключения — в `reviews/`. Машинное восстановление не подменяет прочтение и педагогический аудит; исходные снимки остаются неизменными доказательствами проверяемой версии.

## Воспроизведение

В рабочей копии зафиксированной версии установить зависимости из `scripts/stepik_uploader/requirements.txt`, затем из корня выполнить:

```sh
python 90_reviews/semantic-step-audit-2026-09-20/reconstruct.py
```

Скрипт проверяет соответствие учебных исходников и кода зафиксированному коммиту, использует реальные сохранённые адреса пяти вложений и отказывается объявлять восстановление точным при несовпадении отпечатков. Запуск записи в Stepik отсутствует. Использованная версия Mistune: `3.3.4`; проверяемые отпечатки подтвердили совместимость результата.
