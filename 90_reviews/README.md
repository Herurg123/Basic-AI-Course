# Independent reviews

Заключения независимых критиков по Pull Request, если аудит оформляется отдельным документом.

Минимум аудита: соответствие манифесту, сохранность архитектуры, ориентация на абсолютного новичка, зависимости, переносимость навыка, отсутствие регрессий и скрытого усложнения.

Автор изменения не может быть единственным аудитором собственного Pull Request.
