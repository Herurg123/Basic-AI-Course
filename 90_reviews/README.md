# Critical reviews

Здесь хранятся заключения критических аудитов по Pull Request и сквозных course-level gates, если аудит оформляется отдельным документом.

Рабочий чат или агент запускает критический аудит автоматически после подготовки PR, без ожидания отдельной команды владельца проекта.

Минимум аудита: соответствие манифесту, сохранность архитектуры, ориентация на абсолютного новичка, зависимости, переносимость навыка, отсутствие регрессий и скрытого усложнения.

Проверочный проход должен быть отделён от авторского по роли и цели. При наличии отдельного чата, агента или модели используется отдельный проверочный контекст; иначе выполняется отдельный adversarial-проход с явным чек-листом.

Положительное заключение разрешает немедленный merge. Критическая проблема или необходимость решения владельца проекта останавливает merge и выносится на обсуждение.
