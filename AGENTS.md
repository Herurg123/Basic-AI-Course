# AGENTS.md

Этот файл задаёт краткие рабочие правила для ИИ-агентов и чатов, работающих с репозиторием курса «ИИ с нуля».

## Перед началом работы

1. Прочитать актуальную инструкцию проекта в `00_governance/project-instructions/`.
2. Прочитать актуальный утверждённый манифест в `00_governance/manifest/`.
3. Для архитектурных задач изучить относящиеся к ним утверждённые документы в `01_architecture/`.
4. Не считать авторские статьи или рабочий промпт источником, способным незаметно переопределить утверждённый принцип.

## Правила изменений

- `main` содержит только утверждённое состояние проекта.
- Содержательные изменения готовятся в отдельной ветке.
- Текстовые мастер-файлы хранятся в Git-дружественном формате, обычно Markdown.
- DOCX/PDF являются производными версиями для людей, согласования и Stepik и не редактируются независимо от канонического исходника.
- Изменения попадают в `main` только через Pull Request.
- После подготовки PR рабочий чат или агент сам запускает отдельный критический аудит без ожидания команды пользователя.
- Критический проход должен быть отделён от авторского по роли и цели. При наличии отдельного чата, агента или модели используется отдельный проверочный контекст; иначе проводится отдельный adversarial-проход с явным чек-листом.
- Критик проверяет соответствие манифесту, целостность архитектуры, ориентацию на абсолютного новичка, переносимость навыков и отсутствие регрессий.
- Некритические замечания исправляются самостоятельно, после чего аудит повторяется.
- Если критик одобрил PR и критических замечаний нет, PR сразу сливается в `main` без ожидания дополнительного подтверждения пользователя.
- Если критик выявил критическую проблему или требуется решение владельца проекта, merge запрещён; проблема и варианты решения сообщаются владельцу.
- После значимого PR актуализируются `README.md` и `AGENTS.md`, если изменилось состояние проекта или рабочие правила.

## Основной принцип курса

Мы учим пользоваться современным ИИ как классом инструментов. Конкретный сервис используется для практики, но не является содержанием навыка.
