# Governance

Нормативный слой проекта. Здесь хранятся документы, которые определяют правила разработки курса.

## Разделы

- `manifest/` — актуальный манифест и история утверждённых версий.
- `project-instructions/` — общая инструкция проекта.
- `decision-log/` — журнал существенных проектных решений.

Текстовые нормативные документы хранятся канонически в Git-дружественном формате, обычно Markdown. DOCX/PDF являются производными экспортами для людей и публикации.

Изменения нормативного слоя допускаются только через Pull Request и обязательный критический аудит. После положительного заключения PR сливается автоматически; критическая проблема или необходимость решения владельца останавливает merge.
