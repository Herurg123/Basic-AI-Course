# Project instructions

Здесь хранится актуальная общая инструкция проекта, на которую ссылаются инструкции ChatGPT Project и специализированные чаты.

Канонический рабочий формат в GitHub — Markdown. Ветка `main` является единственным утвержденным состоянием проектных документов.

Текущий файл:

`project-instructions-v1.3.md`

DOCX создаётся как производная bootstrap-копия для общих источников ChatGPT Project и для чтения человеком. Общие источники больше не являются зеркалом GitHub: кроме bootstrap-копии инструкции, Git-tracked нормативные, архитектурные и производственные документы туда не дублируются.

При расхождении bootstrap-копии с GitHub действующей считается версия в `main`. История предыдущих версий сохраняется средствами Git.
