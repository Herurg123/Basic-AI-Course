# Project instructions

Здесь хранится актуальная общая инструкция проекта, на которую ссылаются инструкции ChatGPT Project и специализированные чаты.

Канонический рабочий формат в GitHub — Markdown.

Текущий файл:

`project-instructions-v1.2.md`

DOCX создаётся как производная версия для общих источников проекта, передачи людям и других сценариев чтения. Изменения сначала вносятся в Markdown, затем экспортируются в DOCX.

История предыдущих версий сохраняется средствами Git.
