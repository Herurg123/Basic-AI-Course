# Manifest

Здесь хранится актуальная утверждённая версия документа «Манифест и продуктовые принципы».

Канонический рабочий формат в GitHub — Markdown.

Текущая версия:

- [`manifest-v1.3.md`](manifest-v1.3.md) — нормативное точечное обновление возрастной границы продукта;
- [`manifest-v1.2.md`](manifest-v1.2.md) — полный базовый текст, который продолжает действовать во всех положениях, не изменённых v1.3.

Версия 1.3 имеет приоритет в затронутых ею возрастных формулировках. Решение-основание: [`D-2026-09-11-AGE`](../decision-log/2026-09-11-age-platform-boundary.md).

DOCX/PDF при необходимости создаются как производные версии для передачи людям, согласования и публикации, но не являются отдельным мастер-источником.

История изменений сохраняется средствами Git; отдельные старые копии без необходимости не дублируются.
