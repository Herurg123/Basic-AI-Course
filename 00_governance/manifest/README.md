# Manifest

Здесь хранится актуальная утверждённая версия документа «Манифест и продуктовые принципы».

Канонический рабочий формат в GitHub — Markdown.

Текущий файл:

`manifest-v1.2.md`

DOCX/PDF при необходимости создаются как производные версии для передачи людям, согласования и публикации, но не являются отдельным мастер-источником.

История изменений сохраняется средствами Git; отдельные старые копии без необходимости не дублируются.
