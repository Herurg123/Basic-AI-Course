# Проектная карточка `M06-L01` — Найдите основание за пределами ответа ИИ

> Производственная спецификация проверки по внешнему основанию, не ученический текст.

## A. Идентификация
- `M06-L01` / M06 «Решите, чему доверять и что применять»; тип: проверка; v1.0.
- Exercises: `M06-L01-E01`, `M06-L01-E02`; Check: `M06-L01-C01`.
- Assets: `M06-L01-A01`, `M06-L01-A02`.

## B. Функция урока
До основной практики ученик впервые **сопоставляет вместе три наблюдаемые ситуации происхождения основания**: внешнее основание ответа не установлено; ответ дан по переданному материалу; использование поиска действительно наблюдаемо. Затем ученик выделяет существенный внешний факт, ищет и **открывает** подходящий официальный/первичный источник, сопоставляет условия, при необходимости исправляет вывод и использует подтвержденную пригодную часть в малом действии. Это PRACTICE A1 и полного B10 с новым типом основания, не финальный самостоятельный зачет.

## C. Компетенции
A1/B9/B10/B11/C3 PRACTICE; C1 PRACTICE; B12 PRACTICE; B0–B6 REUSE по ситуации. Поддержка уровня 2: происхождение наблюдаемой опоры разбирается на нейтральной мини-тренировке; тип «официальный/первичный источник» изучается с опорой, само основание не выдается готовым.

## D. Результат
После урока ученик сможет **не приписывать ответу скрытое основание, различать «не установлено / переданный материал / наблюдаемый поиск», а для существенного внешнего факта найти и открыть подходящий официальный/первичный источник, сопоставить его с утверждением и принять решение** на уровне 2. Доказательство основной практики: утверждение + выбранный источник/ссылка + найденный фрагмент/условия + статус + решение + след малого применения. Перед ней — небольшое learner-facing сравнение трёх видов наблюдаемой опоры без отдельного нового Check ID.

## E. Входные требования
Ранняя практика работы по переданному материалу M00-L02; ранняя практика B9/B10/B11; цифровая операция открытия источника из M00. Нужны браузер/поиск и чат. Ученик не обязан знать внутреннюю историю генерации ответа и не обязан использовать встроенный поиск ИИ. Можно напомнить признаки официального/первичного источника; нельзя дать готовую ссылку, если она является содержательным выбором упражнения.

## F. Технический маршрут
Обычный браузер/поиск + утвержденный PRIMARY/BACKUP чат. Встроенный поиск ИИ может помочь найти ссылку, но **не заменяет открытие самого основания**. Факт использования поиска считается установленным только по наблюдаемому действию/интерфейсному следу; наличие ссылки, уверенный тон или заявление модели сами по себе его не доказывают. Если происхождение внешнего основания установить нельзя, корректная категория — «не установлено». Риск SOURCE-QUALITY/FACT: если надежное основание не найдено, не симулировать подтверждение; статус «данных недостаточно». B10 сервис-независим. Динамическая часть — доступ чата/браузера по общей Матрице; сервисная база 2026-09-10; acceptance здесь не проводился.

## G. Первое действие
Перед E01 короткая мини-тренировка на трёх посторонних случаях: обычный чат без наблюдаемого поиска; вопрос по прикреплённому расписанию; явно запущенный и показанный интерфейсом поиск. Ученик сначала сам выбирает категорию, затем видит разбор. После этого из ответа по `M06-L01-A01` выбирает внешний факт, ошибка в котором повлияет на решение. До действия: сам факт ссылки/поиска не доказательство; источник нужно открыть. Ориентир 4–6 мин. вместе с мини-тренировкой.

## H. Exercises
### Мини-тренировка A1 перед `E01`
Три learner-facing ситуации без нового ID:
- обычный чат, без файла и наблюдаемого поиска, но в ответе есть ссылка → внешнее основание **не установлено**;
- прикреплённый учебный материал и вопрос по нему → наблюдаемая опора на **переданный материал**;
- пользователь явно запускает поисковую функцию, интерфейс показывает поиск/результаты → **использование поиска наблюдаемо**, но содержание источников всё равно требует проверки.
Цель — убрать скрытое требование угадывать внутреннюю историю модели до M06-L04.

### `M06-L01-E01`
Из ответа выделить существенный внешний факт; ученик объясняет последствия возможной ошибки.
### `M06-L01-E02`
Найти и открыть подходящий официальный/первичный источник, сопоставить условия, исправить вывод при необходимости и использовать подтвержденную пригодную часть в небольшом безопасном действии. `A02` задает критерии пригодности источника, но не готовую ссылку.

## I. Checks
### `M06-L01-C01`
Зачет: источник подходит утверждению; реально открыт; условия сопоставлены; статус и следующее действие обоснованы содержанием источника. Непрохождение: доверие названию сайта/ссылке/самопроверке ИИ, неоткрытый источник, нерелевантное основание или применение при отсутствии подтверждения. Доказательство — полная цепочка факт → источник → фрагмент → статус → решение → малое применение.

Мини-тренировка трёх видов опоры не является самостоятельным level-3 Check; она является необходимой подготовкой A1 к будущему `M06-L04-C01`.

## J. Уменьшение поддержки
В этом уроке все три категории наблюдаемой опоры сначала объяснены вместе, а тип основания основной практики ещё назван и критерии источника изучаются с поддержкой; конкретный источник и релевантный фрагмент выбирает ученик. В M06-L04 категории уже не будут вводиться впервые и тип проверки не будет подписан.

## K. Объяснение решения
- По каким наблюдаемым признакам вы можете или не можете сказать, на что опирался исходный ответ?
- Почему именно этот факт существенен?
- Почему выбранный источник подходит для проверки?
- Что конкретно в нем изменило или подтвердило вывод?

## L. Перенос
Следующие уроки меняют тип основания: число/расчет и отсутствие надежного основания. Здесь важно не привязать B10 к «поиску ссылки» как единственному методу и не спутать «ИИ показал ссылку» с установленным фактом использования поиска. В M06-L04 ученик сам распознаёт нужное действие, но классификация опоры уже знакома.

## M. Safety / Privacy
Сценарий безопасный и не высокорисковый. Не вводить чувствительные данные. Если основание не найдено, безопасное действие — не применять вывод как подтвержденный.

## N. B9/B10/B11
- Существенное: внешний факт с последствием для решения.
- Наблюдаемая опора исходного ответа: «внешнее основание не установлено» / переданный материал / наблюдаемый поиск; скрытую историю не угадывать.
- Основание проверки: официальный/первичный источник, реально открытый учеником.
- Сопоставление: утверждение ↔ условия/фрагмент.
- Статусы: подтверждено / частично / не подтверждено / данных недостаточно.
- Решение: использовать/исправить/проверить дальше/не применять. Вторая модель, «проверь себя», наличие ссылки и сам факт поиска не доказательство содержания.

## S. Stepik mapping
Короткое объяснение трёх видов наблюдаемой опоры → мини-сравнение трёх посторонних случаев → `E01` → рамка пригодности источника → `E02` в браузере → `C01` → малое применение/объяснение. Тест не заменяет открытие источника и сопоставление. Мини-тренировка не раскрывает три самостоятельных кейса M06-L04.
