# Проверьте исходные числа и расчёт

Калькулятор хорошо считает то, что вы ему дали. Он не умеет автоматически выяснять, были ли исходные числа правильными.

Поэтому **правильная арифметика на неверных исходных данных не является правильным результатом**.

В этом уроке вы проверите оба слоя: откуда взялись числа и сходится ли расчёт.

## Первое действие: что здесь влияет на решение

<!-- Exercise: M06-L02-E01 -->

Откройте [`M06-L02-A01`](../../../05_assets/M06/M06-L02/M06-L02-A01.md).

Там есть исходные данные и подготовленный расчёт ИИ.

Сами выберите число или условие, ошибка в котором способна изменить решение по задаче. Коротко объясните:

**Что станет другим, если это значение неверно?**

Не пытайтесь угадать «число, которое задумал автор». Проверяйте то, что реально влияет на итог.

## Проверьте входные значения, а потом арифметику

<!-- Exercise: M06-L02-E02 -->

1. Откройте исходные данные в `A01`.
2. Для каждого значения, которое нужно вашему расчёту, установите, **откуда оно взялось**.
3. Сопоставьте исходные значения с теми, которые использованы в расчёте ИИ.
4. Отдельно выполните вычисление обычным калькулятором.
5. Дайте итоговому выводу один статус:
   - **подтверждено**;
   - **частично подтверждено**;
   - **не подтверждено**;
   - **данных недостаточно**.
6. Решите, что делать: использовать, исправить, проверить дальше или не применять.

Можно получить техническую помощь по работе с калькулятором. Но до вашего действия вам не должны сообщать, **какое число ошибочно, каким должен быть правильный итог или какое решение принять**.

## Сделайте маленькое действие с пригодным результатом

Если после проверки итог пригоден, запишите в отдельную учебную заметку:

- проверенный итог;
- короткое решение по условию задачи.

Если исходных данных не хватает, не подставляйте догадку только ради красивого числа.

## Проверка действия

<!-- Check: M06-L02-C01 -->

Для зачёта покажите:

- какое значение вы сочли существенным и почему;
- происхождение всех нужных входных чисел;
- ваш отдельный расчёт калькулятором;
- сопоставление с расчётом ИИ;
- статус;
- решение;
- след маленького безопасного применения пригодного результата.

Не засчитывается:

- проверка только арифметики без происхождения входных чисел;
- использование цифр из ответа ИИ как их собственного основания;
- правильный пересчёт на неподтверждённых входах;
- статус, который не соответствует найденным данным;
- применение результата при `данных недостаточно`.

## Если основной маршрут не работает

Чат здесь нужен только как объект работы; проверка не зависит от его встроенного поиска. PRIMARY — Алиса AI, BACKUP — авторизованный GigaChat.

Для вычисления используйте обычный доступный вам калькулятор. Если вы не знаете, как ввести действие, допустима техническая подсказка по клавишам/интерфейсу, но не готовый результат.

## Итог

Проверка числа состоит из двух разных вопросов:

**Верны ли входные данные?**  
**Верно ли выполнено вычисление?**

Только второй вопрос без первого даёт очень аккуратный способ уверенно ошибиться.
