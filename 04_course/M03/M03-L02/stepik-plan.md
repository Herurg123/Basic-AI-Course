## Рекомендательный порядок Stepik для C01

Обычный quiz **не заменяет** `M03-L02-C01`.

Stepik может позволить ученику открыть `C01` до завершения `E01`. Это ограничение платформы не является blocker само по себе. Поэтому непосредственно перед `E01` ученик получает спокойную рекомендацию:

> Сначала выполните самостоятельную попытку и сохраните свой результат. Следующий шаг содержит критерии проверки, которые могут подсказать ход решения. Stepik может позволить открыть его раньше, но лучше этого не делать: иначе вы лишите себя честной проверки того, что уже умеете самостоятельно.

До попытки по-прежнему нельзя добавлять чек-лист «сформулируйте цель → задайте критерии → добавьте контекст → оцените → уточните» или специальное поле «запишите критерии»: это уже содержательная подсказка проверяемого действия.

Если ученик всё же прочитал `C01` заранее, сам факт навигации не наказывается. Если прочитанное могло содержательно повлиять на попытку, исходный `A01` остаётся полезной PRACTICE, а для level-3 re-check используется R1 из `author-notes.md`. Повтор всего урока не требуется.

### Временной evidence для B1

После открытия C01 B1 засчитывается только тогда, когда цель и 1–3 собственных критерия уже видны в артефакте, созданном **до первой оценки результата**. Допустимые примеры: первое сообщение ученика ИИ, самостоятельно созданная до оценки заметка/черновик или запись наблюдателя. Самоутверждение после открытия рубрики «я думал об этих критериях раньше» доказательством не является.

Если более раннего B1-trace нет, B1 уровня 3 имеет статус `NOT PROVEN`, даже если критерии, названные задним числом, разумны. После раскрытия рубрики для повторного level-3 check используется содержательно другая ситуация R1.

Для асинхронного Stepik нельзя полагаться на поле, которое ученик заполняет только после E01 и которому невозможно доказать более раннее время. Нужен уже существующий trace из самой работы либо иное наблюдаемое доказательство времени.

**Quiz допустим:** только дополнительно после C01, например на распознавание того, почему «сделай лучше» не является конкретной доработкой.  
**Quiz не заменяет:** собственную постановку и критерии, самостоятельное решение по существенному условию, оценку первой версии, конкретную доработку, сравнение версий и реальное малое применение.
