# Author notes — M07-L01

> Не ученический маршрут. Используется для защиты F1 rehearsal от скрытого пошагового scaffold.

## 1. Роль

`M07-L01` = F1 INTRO + PRACTICE, уровень 2. Он не закрывает F1 и не должен превращаться в репетицию конкретного алгоритма `M07-L02`.

Разрешена общая поддержка. Нельзя сообщать последовательность действий или требовать все изученные функции.

## 2. Контроль A01

Учебная ситуация намеренно решается без файла, изображения, внешнего поиска, второго сервиса и обязательного расчёта.

В ней естественно нужны несколько знакомых действий: определить пригодный результат по заданной ситуации, использовать данные карточки, оценить и при необходимости доработать текст, заметить существенное расхождение после E02 и довести итог до учебного применения.

Не добавлять новые обязательные действия ради «полноты интеграции».

## 3. Контроль E02

Новая информация A01 сообщает факт изменения. Она **не говорит**, какой приём использовать дальше.

PASS practice: ученик сам выбирает разумное знакомое действие и связывает его с обнаруженной проблемой.

Если автор заранее говорит конкретную правку или последовательность, E02 перестаёт проверять C1 practice.

## 4. C01 и false PASS

Не засчитывать, если:
- хороший текст остался только в чате;
- ученик механически выполнил все пункты памятки как обязательные;
- автор фактически провёл его по шагам;
- после E02 конкретный следующий шаг был подсказан;
- использован новый обязательный приём, которого раньше не было;
- F1 объявляется закрытым после этого урока.

## 5. Red-team A02

A02 проходит self-red-team только если:
- пункты можно читать в любом порядке;
- некоторые пункты могут быть неприменимы;
- нет глагольной цепочки «сначала → затем → потом»;
- нет готового workflow;
- нет ответа на E02;
- по A02 невозможно автоматически воспроизвести финальный F1.

Итог author check: `PASS`, если все условия выше сохранены в production.
