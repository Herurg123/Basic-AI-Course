# Course production

Рабочие и утверждённые материалы модулей и уроков курса.

## Проектные карточки v1.0

Канонический производственный слой перед написанием полных уроков: 21 `lesson-card.md` по утверждённым Lesson ID. Карточки не являются ученическими текстами, финальными заданиями, скриншотами или Stepik-экранами.

Статус определяется веткой: в рабочей ветке `production/lesson-cards-v1.0` карточки являются проектом; после положительного критического аудита и merge в `main` — утверждённым производственным контрактом.

## Граница этапа

На этом слое не создаются `lesson.md`, `student-text.md`, финальные тесты, интерфейсные скриншоты и готовые assets. Следующий отдельный gate после утверждения карточек — приемочная проверка быстро меняющегося сервисного маршрута перед производством интерфейсно-зависимых материалов.
