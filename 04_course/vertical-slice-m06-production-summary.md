## 5. Проверочная траектория M06

### M06-L01

PRACTICE полного B10 на официальном/первичном основании:

`существенный внешний факт → самостоятельный поиск → реальное открытие источника → релевантный фрагмент/условия → статус → решение → малое безопасное применение`.

Готовая ссылка не выдаётся. Встроенный AI-search может найти кандидата, но не заменяет открытие источника.

### M06-L02

PRACTICE числа/расчёта специально атакует ложный PASS «калькулятор сошёлся».

Контролируемая ошибка находится во входном количестве, а арифметика подготовленного ответа по ошибочному входу верна. Author-only A02 хранит контрольный результат и не показывается до действия.

### M06-L03

PRACTICE формирует допустимый результат `данных недостаточно` и действие `не применять / проверить дальше / остановиться / обратиться к ответственному специалисту`.

Использованы только вымышленные ситуации; реальных high-stakes решений и профессиональных заключений нет.

### M06-L04

INDEPENDENT level 3:

`A1, A2, B9, B10, B11, B12, C1, C2, C3`.

Перед попыткой не раскрываются метод, критерий, существенный claim, источник, число, ошибка, статус или решение.

C01 содержит три новые конструкции; полный B10 объединяет их с ранее принятым `M04-L03-C02`.

C02 требует реального малого применения вне ответа модели.

C03 переносит принцип в новую техническую область и объединяется с ранее сохранённым `M03-L02-C02`; второй сервис заново проходить не нужно.

При содержательном загрязнении попытки используются hidden R1/R2/R3 из `author-notes.md` под существующим Check ID.

## 6. Stepik

Применено `D-2026-09-12-STEPIK-FLOW`.

Для M06-L04 используется learner-facing advisory:

- сначала выполнить и зафиксировать самостоятельную попытку;
- затем открыть C01;
- объяснить, что ранняя рубрика может подсказать ход решения;
- не изображать hard gate, которого Stepik не гарантирует;
- при реальном содержательном влиянии использовать новую ситуацию.

Ограничение Stepik не ослабляет evidence: действия должны быть реально выполнены, privacy/safety соблюдены, содержательная подсказка level-3 attempt не получает independent PASS.

## 8. Safety / privacy

- реальные чувствительные данные не требуются;
- high-stakes реальные медицинские, юридические и финансовые решения исключены;
- M06-L03 использует только вымышленные ситуации;
- при недостатке надёжного основания допустим и иногда обязателен результат `не применять`;
- screenshots evidence, если используются учеником, должны быть обезличены.
