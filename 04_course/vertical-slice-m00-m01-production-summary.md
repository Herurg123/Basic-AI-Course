Блокирующих содержательных production items нет.

Есть governance-конфликт финишного workflow: task-specific production instruction требует остановиться с готовой веткой до отдельного audit-чата и не открывать финальный PR; Project Instructions v1.3 / AGENTS.md требуют после подготовки открыть PR, автоматически запустить отдельного критика и при PASS сразу merge. Исправления, уже внесенные в production:

- поиск файла вводится на готовом безопасном asset, а не на личном документе;
- «работа по материалу» объясняется на контрасте с общим вопросом;
- M01-L01 явно разрешает закончить без искусственного поиска ошибки, если критерий уже выполнен;
- «применить» связано с конкретным действием вне чата;
- M01-L02 требует открыть исходник до статуса;
- сохранение результата объяснено без привязки к одной кнопке.

## 13. Anti-bloat pass

Удалены/не включены:

- история ИИ и классификация моделей;
- теория «галлюцинаций» до первого действия;
- универсальная формула идеального промпта;
- повторные лекции о privacy;
- полные параллельные инструкции для BACKUP;
- интерфейсные детали, не нужные для действия;
- декоративные мотивационные абзацы.

Каждый оставшийся блок выполняет функцию действия, понимания, safety, проверки, самостоятельности или переноса.

## 14. Pilot watchlist

Это гипотезы для будущего живого пилота, а не доказанные проблемы:

- ученик не понимает, что значит «новый чистый диалог»;
- трудно найти скачанный/подготовленный файл;
- upload элемент в текущем UI неочевиден;
- ученик не различает общий ответ и ответ по материалу;
- ученик ищет ошибку, хотя ответ уже удовлетворяет критерию;
- уточнение превращается в «сделай лучше»;
- применение остается только словесным;
- ссылка воспринимается как достаточное доказательство;
- исходник фактически не открывается;
- статус «данных недостаточно» ошибочно трактуется как «скорее подтверждено».
