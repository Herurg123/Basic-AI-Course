# Author notes — M01-L02

Этот файл содержит ключ для автора/проверяющего и не должен публиковаться ученику как готовый ответ до выполнения проверки.

## Живая E01 по M01-L02-A01

Основной маршрут E01 теперь начинается с живого ответа ИИ по контролируемому `M01-L02-A01`. Ученик сам выбирает одно утверждение, ошибка в котором изменила бы подготовку участника.

Для живого ответа **нет заранее заданного единственного статуса**. Проверяющий оценивает фактическую пару `утверждение → фрагмент → статус → решение`. Допустим любой из статусов, если он действительно следует из исходника. Уверенность модели или ссылка без чтения источника не являются основанием.

## Запасной M01-L02-A02

Если живая выдача не дает удобного утверждения для тренировки, используется подготовленный учебный ответ:

> «На учебную встречу обязательно нужен ноутбук».

В `M01-L02-A01` прямо сказано, что ноутбук **не требуется**. Ожидаемый статус для этого запасного пути: **не подтверждено**. Допустимое следующее решение: не включать ноутбук в обязательный список; при необходимости исправить ответ.

## M01-L02-A03

Утверждение: «В аудитории ровно 20 мест».

В предоставленном исходнике количество мест не указано. Ожидаемый статус: **данных недостаточно**. Допустимое решение: не использовать число как факт без дополнительного основания.

## Критические ошибки проверки

- ученик не выбрал существенное утверждение из живого ответа или запасного `A02`;
- исходник фактически не открыт отдельно от ответа;
- статус выбран по уверенности ИИ;
- наличие ссылки принято за подтверждение содержания;
- «в исходнике не написано обратное» трактуется как подтверждение.
