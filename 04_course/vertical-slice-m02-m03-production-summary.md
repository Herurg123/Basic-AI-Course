## 9. Педагогическая траектория

Сохранён переход:

`M01-L02 → M02-L01 → M02-L02 → M03-L01 → M03-L02`.

Фактическая прогрессия:

1. M02-L01: тема → конкретная задача → собственные проверяемые критерии, PRACTICE level 2;
2. M02-L02: существенное условие / осмысленный запрос необходимых вопросов, B2 INTRO+PRACTICE;
3. M03-L01: конкретный недостаток → связанный тип следующего шага → собственное уточнение, C1 INTRO;
4. M03-L02: новая задача без списка приёмов → B1/B2/B5/B6 INDEPENDENT level 3.

Не введён универсальный prompt template. Логика остаётся: достаточно понятно начать → посмотреть результат → заметить нехватку → уточнить.
