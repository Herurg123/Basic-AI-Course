# Owner checklist: что понадобится для автоматизации Stepik

Этот список предназначен владельцу курса. Выполнять всё сразу не требуется: automation-чат должен сначала подготовить код и запросить только следующий необходимый шаг.

## 1. Идентификатор существующего курса

Нужно будет передать automation-чату:

- обычную ссылку на черновой курс Stepik, например `https://stepik.org/course/<COURSE_ID>/...`, **или**
- только числовой `course_id`.

Это не секрет.

## 2. Два вручную созданных первых урока

Они используются как golden sample.

Предпочтительно automation сам определит их через API. Если не сможет однозначно:

- открыть каждый урок в Stepik;
- скопировать обычный URL;
- вернуть URL/числовой Lesson ID.

Секретов здесь нет.

## 3. OAuth application Stepik

Когда automation-чат подтвердит, что код готов к реальному `inspect`:

1. открыть `https://stepik.org/oauth2/applications/` под аккаунтом владельца курса;
2. создать приложение для автоматизации;
3. использовать параметры, совместимые с официальным Stepik API OAuth2 и выбранным flow;
4. получить `client_id` и `client_secret`.

**Не присылать `client_secret` в ChatGPT и не коммитить его в GitHub.**

## 4. Куда положить секреты

Предпочтительный вариант для владельца без локальной Python-настройки — GitHub Actions Secrets.

Automation-чат должен дать точный путь в GitHub UI и точные имена secrets после того, как workflow будет создан.

Ожидаемые имена:

- `STEPIC_CLIENT_ID`;
- `STEPIC_CLIENT_SECRET`.

Альтернатива для локального запуска:

- `.env` / environment variables;
- `.env` обязательно находится в `.gitignore`.

## 5. Stepik Files

Сейчас в интерфейсе курса владельцу доступно:

`Настройки урока → Файлы`

и уже вручную загружены первые примерные DOCX/PNG assets.

Ничего дополнительно загружать заранее не нужно.

Сначала automation должен:

1. проверить, можно ли read/list/upload делать через устойчивый API-маршрут;
2. если нельзя — создать skeleton недостающих уроков;
3. выдать владельцу точный список файлов для каждого Lesson ID;
4. после ручной загрузки попросить вернуть только обычные ссылки `Скопировать ссылку`.

Если Stepik Files перестанут быть доступны в бесплатном курсе, те же Asset ID переводятся на внешний URL-map, первоначальный fallback — Яндекс.Диск.

## 6. Что владелец НЕ должен делать

До завершения inspect/dry-run не нужно:

- вручную создавать оставшиеся 19 уроков;
- вручную создавать все модули;
- копировать весь learner-facing текст в Stepik;
- присылать OAuth secrets в чат;
- самостоятельно придумывать соответствие Stepik types нашим упражнениям;
- удалять два вручную созданных golden lessons.

## 7. Финальная ручная проверка

Даже после успешного API upload владелец/оркестратор должен визуально открыть тестовый урок и проверить learner-facing результат.

API `201 Created` означает только то, что сервер согласился создать объект. Это не педагогическое достижение и, к сожалению, не сертификат здравого смысла.
