# Официальные источники Stepik для automation

**Проверено:** 14 сентября 2026 года.

Этот файл фиксирует внешние быстро меняющиеся платформенные источники, на которых основан automation handoff. Перед реализацией uploader их нужно перепроверить.

## API

- Работа с API: <https://help.stepik.org/article/64188>
- API docs: <https://stepik.org/api/docs>
- Official Stepik API examples: <https://github.com/StepicOrg/Stepik-API>
- Official create-content example: <https://github.com/StepicOrg/Stepik-API/blob/master/examples/create_content.py>
- Official course copy/export example: <https://github.com/StepicOrg/Stepik-API/blob/master/examples/copy_paste_course.py>

На дату проверки Stepik прямо указывает, что REST API используется для основных функций работы с контентом и подходит для переноса курса с другой платформы. Stepik также предупреждает, что отдельные редко используемые функции могут быть доступны только через базовый web UI.

## Файлы курса/урока

- Добавление файлов на Stepik: <https://help.stepik.org/article/54826>
- Настройки курса / раздел «Файлы»: <https://help.stepik.org/article/54807>

На дату проверки официальная справка указывает:

- файл можно добавить к курсу или уроку;
- максимальный размер одного файла — 25 МБ;
- учащемуся файл становится доступен через ссылку, помещённую автором в шаг;
- функция помечена как доступная для платных курсов.

При этом владелец проекта фактически видит и использует `Настройки урока → Файлы` в текущем черновом курсе. Это фактическое наблюдение не отменяет необходимость перепроверить доступность после перехода к бесплатной публикации.

## Шаги и импорт

- Добавление шагов: <https://help.stepik.org/article/54791>
- Виды шагов: <https://help.stepik.org/article/54792>
- Добавление задач в курс файлом: <https://help.stepik.org/article/54824>

CSV-import задач не является базовым маршрутом для нашего курса: Stepik поддерживает там только тестовые задачи, причём каждая импортированная задача становится отдельным уроком. Это не соответствует канонической структуре 9 модулей / 21 Lesson ID.

## Редактирование после публикации

- Настройки курса: <https://help.stepik.org/article/54807>
- Как создать урок и курс / публикация: <https://help.stepik.org/article/54788>
- Структура курса и её создание: <https://help.stepik.org/article/54789>
- Доступ к курсу и уроку: <https://help.stepik.org/article/54813>

На дату проверки официальная справка Stepik подтверждает, что авторы могут продолжать редактировать описание и содержание курса, а после внесения изменений обновлять публикационный чек-лист. Публичность курса и публичность отдельного урока являются разными настройками.

Следствие для нашей automation: первый массовый upload остаётся draft-only, но эксплуатационный correction-sync должен уметь безопасно обновлять уже существующие шаги и после публикации курса. Сам uploader не должен автоматически менять режим публикации курса или lesson visibility.

## Правило использования

Если фактическое поведение текущего Stepik расходится с этими страницами, automation-чат не выбирает удобную версию молча. Он фиксирует расхождение и проверяет реальный API/web contract на тестовом объекте до массового upload.
