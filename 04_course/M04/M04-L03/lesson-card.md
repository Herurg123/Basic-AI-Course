# Проектная карточка `M04-L03` — Решите новую задачу по своему материалу

> Производственная спецификация самостоятельного переноса, не ученический текст.

## A. Идентификация
- `M04-L03` / M04 «Решите задачу по своему материалу»; тип: самостоятельный перенос; v1.0.
- Exercises: `M04-L03-E01`, `M04-L03-E02`; Checks: `M04-L03-C01`, `M04-L03-C02`.
- Assets: `M04-L03-A01`, `M04-L03-A02`.

## B. Функция урока
Ученик сам решает использовать собственный безопасный материал, ставит по нему новую задачу, различает основание ответа, без готового указания сверяет существенное с исходником и использует пригодную версию. Здесь B4 достигает уровня 3, а B10 самостоятельно доказан **только в конструкции «по материалу»**. Не входит полный B10 других типов, который остается M06-L04.

## C. Компетенции
- B4 INDEPENDENT уровень 3.
- B10 INDEPENDENT уровень 3 **частично: по материалу**.
- A1/B9/B11/B12/C1/C2/C3 PRACTICE; B3 REUSE.
Интерфейсная помощь допустима; готовый выбор материала, утверждения или фрагмента недопустим.

## D. Результат
После урока ученик сможет **самостоятельно выбрать собственный безопасный материал, решить по нему новую задачу и проверить существенное утверждение по самому исходнику**. Доказательство: безопасный собственный материал/описание + запрос + результат + утверждение + фрагмент + статус/решение + след применения.

## E. Входные требования
B3 уже INDEPENDENT; B1/B2/B5/B6; M04-L01; цифровые действия M00. Материал выбирается учеником в поддерживаемом пересечении форматов либо вставляется текстом. Нельзя считать готовый asset курса «собственным» и нельзя подсказывать, что именно сверять.

## F. Технический маршрут
PRIMARY Алиса AI; BACKUP GigaChat. Для BACKUP собственный материал не должен содержать персональные данные/охраняемые тайны по ограничениям SM. Если материал нельзя безопасно подготовить, выбирается другой; обязательное действие не заменяется готовым файлом курса. [DYNAMIC] Y3 `https://alice.yandex.ru/support/ru/assistant/chat/files`, G4 `https://giga.chat/help/articles/work-with-docs`; база 2026-09-10. Acceptance: актуальные форматы/лимиты/upload и ответ по материалу; здесь не проводился.

## G. Первое действие
По `M04-L03-A01` выбрать **собственный нейтральный** материал и до upload применить B3. Автор проверяет только допустимость, не выбирает материал вместо ученика. Ориентир 3 мин.

## H. Exercises
### `M04-L03-E01`
Выбрать собственный безопасный материал и самостоятельно поставить новую задачу. «Собственный» может быть нейтральная заметка/список, созданный учеником; готовый asset курса не засчитывается.
### `M04-L03-E02`
Получить результат, самому определить существенное утверждение для сверки по этому материалу, открыть исходник, найти основание, присвоить статус и использовать пригодную версию по назначению. B12 здесь PRACTICE, не финальный зачет.

## I. Checks
### `M04-L03-C01`
- **B4, уровень 3:** самому выбрать собственный безопасный материал и поставить новую задачу по нему.
- **Зачет:** материал релевантен и допустим; задача конкретна; ответ действительно связан с материалом.
- **Непрохождение:** готовый asset курса вместо собственного материала или содержательная подсказка выбора.
- **Доказательство:** безопасный материал/описание + запрос + результат.

### `M04-L03-C02`
- **B10, уровень 3 частично:** самому выбрать существенное утверждение ответа по своему материалу, открыть исходник и сопоставить.
- **Зачет:** вывод по фрагменту корректен.
- **Непрохождение:** источник не открыт, фрагмент не относится к утверждению или метод/ответ подсказан содержательно.
- **Доказательство:** утверждение + фрагмент + статус + решение.
- Этот зачет **не заменяет** полный B10 `M06-L04-C01`.

## J. Уменьшение поддержки
Учебный материал M04-L01 → собственный допустимый материал → самостоятельный выбор утверждения/фрагмента. Только техническая помощь. Содержательная подсказка делает попытку PRACTICE и требует другой задачи/материала.

## K. Объяснение решения
- Почему выбрали именно этот материал и почему его допустимо передавать?
- Почему это утверждение существенно для вашей задачи?
- На каком фрагменте основан статус?

## L. Перенос
Новая задача по **собственному** материалу, не повтор учебного файла. Для C2 меняется область/тип содержания; принцип «материал как основание» сохраняется.

## M. Safety / Privacy
B3 уже освоена и применяется до каждой передачи. Разрешен нейтральный собственный материал, который можно безопасно показать внешнему сервису. Реальные чувствительные сведения/охраняемые тайны запрещены. Сомнение → обезличить, заменить или выбрать другой материал. Критическая ошибка: передача недопустимого материала.

## N. B9/B10/B11
- Существенное выбирает ученик сам.
- Тип основания: собственный исходный материал.
- Ученик реально открывает и сопоставляет исходник, а не просит ИИ «проверить себя».
- Статусы: подтверждено / частично / не подтверждено / данных недостаточно.
- Решение после проверки связано с задачей. Сам факт ссылки, уверенность ИИ или вторая модель не доказательство.
