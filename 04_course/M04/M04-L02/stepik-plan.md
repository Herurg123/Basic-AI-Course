## Evidence для B3 level 3

Для `M04-L02-C01` недостаточно описать намерение.

- **Обезличивание / замена:** предъявляется фактически подготовленная безопасная версия.
- **Безопасный пересказ:** предъявляется реально написанный пересказ нужного содержания.
- **Отказ:** исходник не загружается; до передачи фиксируются решение «не передаю» и краткая причина.
- **Передать как есть:** допустимо только если ученик самостоятельно обосновывает, что материал нужен задаче и допустим для передачи.

Перечень «что я бы удалил/заменил» без выполненного действия не даёт PASS B3 уровня 3.

Privacy-before-transfer абсолютна: нельзя сначала загрузить условно чувствительный исходник и затем обезличивать его задним числом.

**Порядок Stepik:** рубрика не должна заранее перечислять конкретные поля, которые требуется скрыть; общая safety-рамка до действия допустима и обязательна.  
**Обычный quiz допустим:** только как дополнительная проверка уже разобранного принципа.  
**Quiz не заменяет:** решение до передачи и фактически выполненное обезличивание/пересказ/отказ.  
**Внешнее действие:** для `C01` ИИ-сервис не нужен; после безопасного решения возможна короткая B4-практика.  
**Screenshots:** используется авторский SVG с полностью фиктивными сведениями, не снимок реального аккаунта.
