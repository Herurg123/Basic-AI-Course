# Получите полезный ответ по файлу и сверьте его с файлом

Вы уже передавали учебный документ ИИ. Теперь пойдём дальше: поставим по файлу собственную задачу и затем проверим одно важное утверждение по самому исходнику.

Здесь две разные привычки:

1. безопасно передать материал и ясно сказать, что с ним сделать;
2. не считать ответ ИИ доказательством того, что в файле действительно написано именно это.

## Используйте только подготовленный файл

В этом уроке нужен подготовленный учебный файл. Все данные в нём вымышлены.

Не заменяйте его личным документом. Самостоятельно выбирать собственный материал вы будете чуть позже, когда отдельно потренируетесь решать, что вообще допустимо передавать.

## Поставьте свою задачу по содержанию

<!-- Exercise: M04-L01-E01 -->

Откройте или скачайте [учебный файл](../../../05_assets/M04/M04-L01/M04-L01-A01.txt) и убедитесь, что это именно материал курса с вымышленными данными.

Загрузите его в [Алису AI](https://alice.yandex.ru/) и **сами сформулируйте конкретную задачу**, для которой содержание файла действительно нужно.

Например, результатом может быть короткая памятка, список условий или ответ на конкретный вопрос. Точную задачу выберите сами.

Не просите ИИ просто «рассказать всё о файле». Подумайте, какой результат был бы полезен в этой ситуации.

Сохраните свой запрос и ответ.

## Почему ответ по файлу всё равно нужно проверять

Файл был передан ИИ, но исходным материалом остаётся **сам файл**. Модель может пропустить условие, объединить две фразы или добавить лишний вывод.

Поэтому для важного утверждения полезно вернуться к документу и посмотреть, что там написано.

Не нужно проверять каждое слово. Выберите то, ошибка в чём повлияет на вашу задачу.

## Когда источник поддерживает только часть фразы

Раньше вы использовали три статуса. Теперь нужен ещё один случай: иногда источник подтверждает **часть** утверждения, но не всё существенное содержание.

- **подтверждено** — источник поддерживает всё существенное утверждение;
- **частично подтверждено** — одна существенная часть поддержана, а другая нет;
- **не подтверждено** — источник показывает другое или прямо противоречит утверждению;
- **данных недостаточно** — информации недостаточно для вывода.

Например, если ответ говорит «встреча в 18:30 в кабинете 204», а исходник сообщает только время и ничего не говорит о кабинете, всю фразу нельзя считать полностью подтверждённой.

## Сверьте одно существенное утверждение

<!-- Exercise: M04-L01-E02 -->

В полученном ответе самостоятельно выберите одно утверждение, которое важно для вашей задачи.

Затем:

1. снова откройте учебный файл;
2. найдите относящийся фрагмент;
3. сопоставьте его с утверждением ИИ;
4. выберите один из четырёх статусов;
5. решите, можно ли использовать эту часть ответа без изменения.

Не просите ИИ «проверить себя» вместо открытия файла. Второй уверенный ответ модели тоже не является основанием.

## Как понять, что работа завершена

<!-- Check: M04-L01-C01 -->

У вас должна получиться цепочка:

**безопасный файл → ваша задача → ответ → существенное утверждение → открытый фрагмент файла → статус → решение.**

Коротко покажите свой запрос, выбранное утверждение, найденный фрагмент и решение.

Особенно важно уметь ответить:

**Почему именно этот фрагмент относится к выбранному утверждению?**

Если файл был только загружен, но не открыт повторно для сверки, вернитесь к исходнику. Если задача по файлу осталась расплывчатой, сформулируйте конкретный нужный результат.

## Если основной маршрут не работает

Если анализ файла в [Алисе AI](https://alice.yandex.ru/) временно недоступен, используйте [GigaChat](https://giga.chat/) и тот же учебный файл. Если для загрузки или анализа файла сервис попросит войти, используйте обычный вход по его правилам.

## Что вы уносите из урока

Ответ по документу становится полезнее, когда вы умеете сделать две вещи отдельно: **поставить конкретную задачу по материалу и вернуться к самому материалу для проверки существенного**.
