# Проектная карточка `M04-L01` — Получите ответ по безопасному исходнику

> Производственная спецификация, не ученический текст.

## A. Идентификация
- `M04-L01` / M04 «Решите задачу по своему материалу»; тип: материал + проверка; v1.0.
- Exercises: `M04-L01-E01`, `M04-L01-E02`; Check: `M04-L01-C01`.
- Assets: `M04-L01-A01`, `M04-L01-A02`.

## B. Функция урока
Ученик безопасно работает по содержанию учебного документа и проверяет утверждение ответа, реально открывая исходник. Здесь B3/B4/A1/B9/B10/B11 получают практику перед собственным материалом. Не входит самостоятельный B4/B10, внешний поиск источника или реальные личные документы.

## C. Компетенции
PRACTICE: B3, B4, A1, B9, B10, B11. REUSE: B1/B2/B5/B6. Уровень 1→2; основание предоставлено, поэтому B10 не зачитывается как полный самостоятельный.

## D. Результат
После урока ученик сможет **безопасно передать учебный исходник, поставить задачу по нему и сверить существенное утверждение ответа с конкретным фрагментом материала** с поддержкой 1→2. Доказательство: файл/ID + запрос + утверждение + найденный фрагмент + статус/решение.

## E. Входные требования
B1/B2/B5/B6; минимальная B3; цифровые операции M00. Нужны найти/загрузить документ и открыть его для сверки. Можно объяснить интерфейс; нельзя считать загрузку доказательством правильности или выдавать нужный фрагмент во второй попытке.

## F. Технический маршрут
PRIMARY Алиса AI документы; BACKUP GigaChat в пересечении форматов. Риск PRIVACY/FACT/FORMAT: только учебный безопасный файл; исходник открывает ученик; BACKUP учитывает лимиты/новый чат. [DYNAMIC] Y3 `https://alice.yandex.ru/support/ru/assistant/chat/files`, G4 `https://giga.chat/help/articles/work-with-docs`; проверено 2026-09-10. Acceptance: форматы, загрузка, ответ по содержанию, возврат к исходнику. **Не проводился в этой работе.**

## G. Первое действие
Загрузить `M04-L01-A01`, поставить конкретную задачу по нему. До upload: убедиться, что файл учебный и безопасный. Ориентир 3 мин.

## H. Exercises
### `M04-L01-E01`
Загрузить безопасный учебный документ и поставить задачу. Дан `A01`; ученик формулирует конкретное действие по содержанию.
### `M04-L01-E02`
Выбрать существенное утверждение ответа и сверить его с конкретным фрагментом документа с меньшей опорой. Основание предоставлено, но релевантный фрагмент ученик находит сам.

## I. Checks
### `M04-L01-C01`
Зачет: материал нужен задаче и безопасен; результат связан с ним; ученик реально открывает исходник; статус факта опирается на найденный фрагмент. Непрохождение: доверие ответу/ссылке без открытия материала, нерелевантный фрагмент, чувствительный файл. Доказательство: файл/ID + запрос + утверждение + фрагмент + статус/решение.

## J. Уменьшение поддержки
E01 — явная механика upload и задачи → E02 — меньше опоры, ученик сам выбирает утверждение и находит фрагмент. Самостоятельный B10 по материалу будет в M04-L03.

- Что изменилось бы в решении, если фрагмент не подтверждает ответ?

## L. Перенос
Подготовленный учебный документ служит мостом к собственному безопасному материалу в M04-L03; содержательная самостоятельность пока не переносится.

## M. Safety / Privacy
B3 до upload. Разрешен только `A01` с фиктивными данными; реальные медицинские, банковские, паспортные, рабочие секреты и чужие данные запрещены. При сомнении материал заменить. Критическая ошибка — реальная чувствительная передача.

## N. B9/B10/B11
- Существенное: утверждение ответа по содержанию документа.
- Основание: реально открытый `A01`; ключ `A02` только для автора и не выдается как ответ.
- Сопоставление: утверждение ↔ конкретный фрагмент.
- Статус: подтверждено / частично / не подтверждено / данных недостаточно.
- Решение следует из содержания, а не уверенности ИИ. Вторая модель/«проверь себя» не доказательство.
