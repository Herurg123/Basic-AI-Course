# UX fix batch для абсолютного новичка — 13 сентября 2026

## Основание

После отдельного adversarial UX-аудита всех 21 learner-facing уроков, всех 21 Stepik-планов и ключевых assets был выявлен набор проблем, которые не меняли архитектуру компетенций, но мешали честному самостоятельному прохождению абсолютным новичком.

Владелец проекта принял решение `D-2026-09-13-LEARNER-UX`: сохранить независимость самостоятельных попыток через **нейтральный естественный след работы**, разрешить post-action пояснение уже существующего trace, убрать производственный язык из learner-facing слоя и давать прямые ссылки на сервисы и заранее заданные материалы.

## Что исправлено

### 1. Temporal evidence без скрытого экзамена на документацию

В `M03-L02`, `M06-L04` и финальном `M07-L02` больше не требуется отдельное заранее угаданное поле с названием внутренней компетенции или словом «критерий».

Перед самостоятельной попыткой ученик получает только нейтральную инструкцию сохранять реальные решения по мере работы. После попытки он может пояснить уже существующий естественный след. Позднее объяснение не создаёт действие задним числом и не восстанавливает independence после содержательной подсказки.

### 2. Recovery стал learner-facing

Повторные ситуации после загрязнённой самостоятельной попытки больше не существуют только в author notes:

- `M03-L02` — новая текстовая задача про домашний книжный обмен;
- `M04-L02` — внутренний групповой чат → безопасное публичное объявление;
- `M05-L02` — новая безопасная ситуация для реального редактирования изображения;
- `M06-L04` — три новые ситуации для внешнего источника, числовой проверки и недостатка основания.

Author notes сохраняют скрытый ключ и false-PASS red-team, но не единственную копию обещанного ученику recovery.

### 3. Прямые ссылки

В learner-facing уроках внешнее действие ведёт по прямой ссылке, например:

- [Алиса AI](https://alice.yandex.ru/);
- [GigaChat](https://giga.chat/).

Заранее заданные материалы курса также остаются кликабельными непосредственно в месте действия.

Исключение: готовая ссылка на правильный источник не выдаётся, если самостоятельный поиск/выбор источника сам является проверяемым действием.

### 4. Язык для новичка

Из learner-facing слоя удалены или заменены там, где они не нужны ученику:

- ID компетенций (`B7`, `B8`, `C2`, `F1` и т. п.);
- `level 3`, `PRACTICE`, `PRIMARY/BACKUP`;
- `Asset ID`, `staged view`, `student-facing`, `live-output`;
- лишняя production-терминология вокруг evidence/recovery.

Технические ID сохранены в комментариях, production plans, author notes и путях файлов, где они нужны проекту.

### 5. Термины проверки

В M00 простыми словами введено, что проверяемый признак результата дальше называется критерием.

В M00-L03 разведены понятия «исходный материал», «источник» и «основание».

В M04-L01 явно введён переход от трёх к четырём статусам:

- подтверждено;
- частично подтверждено;
- не подтверждено;
- данных недостаточно.

### 6. Убран скрытый барьер DOCX

В `M00-L02` ученик больше не обязан иметь Word/LibreOffice только для предварительного просмотра учебного DOCX. Если файл не открывается локально, рядом доступна текстовая копия; для упражнения затем загружается сам DOCX.

### 7. Бесплатный Stepik

Добавлена общая learner-facing памятка [`stepik/how-to-save-practice.md`](stepik/how-to-save-practice.md).

Публичный бесплатный маршрут не зависит от платных функций Stepik:

- файлы, изображения, скриншоты и заметки ученик хранит у себя;
- после действия в Stepik используется короткий свободный текст;
- обязательная загрузка файлов в решение и обязательная ручная teacher grading не используются;
- в Human Pilot наблюдатель проверяет фактические артефакты непосредственно;
- курс не изображается как технически защищённая сертификация.

### 8. Динамический вход в Алису AI

Из M00 удалён старый workaround «открыть новую вкладку для чистого анонимного чата» как будто это стабильное правило. Если текущий сервис просит войти для нового чата или истории, learner использует обычный вход по правилам платформы. Динамический маршрут перепроверяется перед публикацией.

## Что не изменено

- 9 модулей M00–M08;
- 21 Lesson ID;
- состав компетенций и их целевые уровни;
- F1 как завершённая собственная реальная задача;
- privacy-before-transfer;
- реальная генерация и реальное редактирование изображения;
- проверка существенного по реальному основанию;
- actual application;
- D-2026-09-12-STEPIK-FLOW.
