**Обычный quiz допустим:** проверить понимание порядка «сначала подготовить безопасную версию, потом решать вопрос о передаче».  
**Quiz не заменяет:** загрузку документа/изображения, постановку задач по их содержанию и фактическое создание безопасной копии `A03` вне AI-чата.  
**BACKUP:** GigaChat предлагается только при недоступности нужной файловой операции в Алисе AI. Для каждого нового файла учитывается отдельный новый чат; задача формулируется заново рядом с загруженным файлом.  
**Вход:** не требовать авторизацию заранее; если конкретная файловая операция просит вход, использовать обычный вход по правилам сервиса.  
**Скриншоты:** не требуются. Если UI загрузки станет неочевидным, это проверяется отдельным publication/service gate; не генерировать фиктивный интерфейс.  
**Бесплатный Stepik:** безопасная версия A03 остаётся у ученика; в Stepik достаточно короткой фиксации уже выполненной работы.  
**Причина до действия:** действует `D-2026-09-13-RATIONALE-BEFORE-ACTION`; смысл передачи конкретного материала и обезличивания расположен до соответствующей практики.
