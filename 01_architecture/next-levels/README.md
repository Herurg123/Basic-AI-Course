# Next levels

Граница завершённой базовой ИИ-грамотности и дальнейшего углубления.

## Действующая карта

- [`next-levels-v1.0.md`](next-levels-v1.0.md) — карта следующих уровней v1.0. Она фиксирует, что уже входит в завершенную бесплатную базу, по каким признакам задача выходит на следующий уровень сложности и какие направления пока считаются только гипотезами будущего развития.

Карта используется в M08 для осмысления дальнейшего маршрута. Она не является каталогом существующих платных продуктов и не может использоваться для изъятия утвержденных базовых компетенций из бесплатного курса.
