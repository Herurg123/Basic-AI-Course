# Общая архитектура курса

Действующая архитектура состоит из:

- [`course-architecture-v1.1.md`](course-architecture-v1.1.md) — нормативное точечное обновление возрастной границы и acceptance/release-зависимостей от 11 сентября 2026 года;
- [`course-architecture-v1.0.md`](course-architecture-v1.0.md) — полный базовый текст архитектуры, который продолжает действовать во всех положениях, не изменённых v1.1.

Версия 1.0 задает 9 модулей M00–M08 и 21 Lesson ID, зависимости, INTRO / PRACTICE / INDEPENDENT / REUSE для всех компетенций, сквозную безопасность и проверку, условия F1 и архитектурные инварианты дальнейшей разработки. Версия 1.1 не меняет эту сетку и снимает отдельный child/parent functional route из внутренних gates проекта.

Полная Матрица покрытия v1.0 уже создана и утверждена отдельно. Нижележащие возрастные формулировки в ней и карточках читаются с учётом Манифеста v1.3, Service Matrix v1.1 и [`D-2026-09-11-AGE`](../../00_governance/decision-log/2026-09-11-age-platform-boundary.md).
