# Общая архитектура курса

Канонический документ — [course-architecture-v1.0.md](course-architecture-v1.0.md).

Версия 1.0 утверждена в `main` и задает 9 модулей M00–M08 и 21 Lesson ID, зависимости, INTRO / PRACTICE / INDEPENDENT / REUSE для всех компетенций, сквозную безопасность и проверку, условия F1 и архитектурные инварианты дальнейшей разработки.

Полная Матрица покрытия v1.0 уже создана и утверждена отдельно. Следующий производственный этап — проектные карточки 21 урока по Стандарту v1.1 и `lesson-template.md`; архитектуру курса на этом этапе заново не проектируют.

Предыдущего полного архитектурного документа в доступных источниках не было; основанием версии 1.0 послужили предварительная структура манифеста и утвержденные архитектурные документы.
