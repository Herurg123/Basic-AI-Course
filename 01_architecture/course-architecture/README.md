# Общая архитектура курса

Канонический документ — [course-architecture-v1.0.md](course-architecture-v1.0.md).

Версия 1.0 задает 9 модулей M00–M08 и 21 предполагаемый урок, зависимости, INTRO / PRACTICE / INDEPENDENT / REUSE для всех компетенций, сквозную безопасность и проверку, условия F1 и границы следующего этапа.

В рабочей ветке документ является проектом; после положительного независимого аудита и merge в `main` — утвержденной архитектурой. Предыдущего полного документа в доступных источниках не было; основанием служат предварительная структура манифеста и утвержденные архитектурные документы.
