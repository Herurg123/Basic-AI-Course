# Service matrix

Живой архитектурный документ с проверенными маршрутами и возможностями сервисов: доступность в России, регистрация, устройства, бесплатные лимиты, нужные функции, резервные варианты, официальный источник и дата проверки. Возрастные условия сторонних сервисов могут фиксироваться как справочные внешние факты, но не являются внутренним acceptance/release-gate курса.

## Действующая версия

- [`service-matrix-v1.2.md`](service-matrix-v1.2.md) — нормативное точечное обновление маршрута GigaChat: гостевой режим используется там, где нужное действие доступно без входа; авторизация требуется только когда её запрашивает сервис для конкретного действия;
- [`service-matrix-v1.1.md`](service-matrix-v1.1.md) — нормативное точечное обновление возрастной границы и release-gate от 11 сентября 2026 года;
- [`service-matrix-v1.0.md`](service-matrix-v1.0.md) — полный базовый текст Матрицы, который продолжает действовать во всех положениях, не изменённых v1.1/v1.2.

Основания изменений: [`D-2026-09-11-AGE`](../../00_governance/decision-log/2026-09-11-age-platform-boundary.md) и актуальная consumer-route проверка GigaChat от 19 сентября 2026 года.

Быстро меняющиеся параметры сервисов перепроверяются непосредственно перед публикацией интерфейсных материалов курса. Канонический рабочий исходник Матрицы хранится в Markdown; производные форматы создаются из него при необходимости.
