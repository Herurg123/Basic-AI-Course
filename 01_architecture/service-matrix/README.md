# Service matrix

Живой архитектурный документ с проверенными маршрутами и возможностями сервисов: доступность в России, возраст, регистрация, устройства, бесплатные лимиты, нужные функции, резервные варианты, официальный источник и дата проверки.

## Действующая версия

- [`service-matrix-v1.0.md`](service-matrix-v1.0.md) — Матрица сервисов курса «ИИ с нуля» v1.0, утверждённая редакция от 10 сентября 2026 года. Вступает в действующее состояние `main` после положительного критического аудита и merge соответствующего Pull Request.

Быстро меняющиеся параметры сервисов перепроверяются непосредственно перед публикацией интерфейсных материалов курса. Канонический рабочий исходник Матрицы хранится в Markdown; производные форматы создаются из него при необходимости.
