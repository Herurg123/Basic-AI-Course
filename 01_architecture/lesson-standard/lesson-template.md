# 8. Acceptance-check / Lesson Gate `[AUTHOR]`

## Компетенция и доказательство

- [ ] Компетенция/закрепление названы.
- [ ] Действие соответствует компетенции.
- [ ] Проверка наблюдает это действие.
- [ ] Хороший ответ ИИ сам по себе не считается доказательством.

## Вход и понятность

- [ ] Входные навыки и цифровые действия названы.
- [ ] Все необходимое объясняется до использования.
- [ ] Язык понятен абсолютному новичку.
- [ ] Нет скрытой платной/VPN/API/англоязычной зависимости.

## Практика и самостоятельность

- [ ] Первое осмысленное действие начинается в первые минуты.
- [ ] Нет длинного пассивного блока.
- [ ] Подсказки соответствуют целевому уровню.
- [ ] Для уровня 3 есть новая задача с меньшей поддержкой.
- [ ] Повтор имеет педагогическую функцию.
- [ ] Ученик объясняет хотя бы одно существенное решение.

## Безопасность и проверка

- [ ] Приватность появляется до передачи.
- [ ] Существенное проверяется до применения.
- [ ] B10, если применяется, использует реальное основание.
- [ ] Допускается вывод «данных недостаточно / не применять».

## Сервис и перенос

- [ ] Навык объясняется как принцип, не как кнопка.
- [ ] PRIMARY/BACKUP соответствуют актуальной Матрице.
- [ ] Есть условие переключения.
- [ ] Динамические факты датированы и имеют источники.
- [ ] Перенос предусмотрен там, где он требуется.

## Производство

- [ ] Есть критерий успеха и описание непрохождения.
- [ ] Нет лишнего материала.
- [ ] Урок можно перенести в Stepik без потери практики.
- [ ] Assets перечислены.
- [ ] ID стабильны.

**Итог Gate:** ПРОЙДЕН / НЕ ПРОЙДЕН
