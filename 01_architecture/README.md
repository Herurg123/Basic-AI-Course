# Architecture

Утверждённые архитектурные документы курса.

## Разделы

- `course-architecture/` — [общая архитектура курса v1.0](course-architecture/course-architecture-v1.0.md).
- `competency-map/` — карта компетенций.
- `service-matrix/` — матрица сервисов.
- `lesson-standard/` — стандарт сценария урока: базовая v1.1 + действующее точечное обновление v1.2 и шаблон.
- `coverage-matrix/` — [полная Матрица покрытия v1.0](coverage-matrix/coverage-matrix-v1.0.md): связь компетенций с 21 уроком, упражнениями, проверками, доказательствами, сервисами, рисками и Asset ID.
- `next-levels/` — [Карта следующих уровней v1.0](next-levels/next-levels-v1.0.md): граница завершенной базы и дальнейшего усложнения; возможные будущие продукты остаются гипотезами до отдельного решения.

Архитектурная сетка и Матрица покрытия утверждены. При производстве и Stepik-сборке уроков действует Lesson Standard v1.2 вместе с базовой v1.1; перед новым осмысленным действием ученик должен понимать, зачем оно нужно, без раскрытия решения самостоятельной задачи.

Рабочие изменения проходят через отдельную ветку и Pull Request. После подготовки PR рабочий чат или агент автоматически запускает обязательный критический аудит. При положительном заключении PR сразу сливается в `main`; критическая проблема или необходимость решения владельца проекта останавливает merge.
