## 9. Авторская проверка покрытия

### 9.1. Результат

- **19/19 компетенций** присутствуют: A1, A2, B0–B12, C1–C3, F1; дополнительных ID компетенций не введено.
- **9/9 модулей** M00–M08 и **21/21 Lesson ID** сохранены без добавления, удаления или переноса.
- B0 имеет целевой уровень **2**; все остальные обязательные компетенции — **3** в пределах простой задачи.
- `INTRO / PRACTICE / INDEPENDENT / REUSE` воспроизведены из CA §10 без изменения мест самостоятельного зачета.
- Частичный самостоятельный B10 по материалу закреплен в `M04-L03-C02`; полный B10 — в `M06-L04-C01`.
- B7/B8 разделены: M05-L01 использует подготовленные авторские версии только для практики; `M05-L02-C01/C02` требуют живой генерации и реальной правки существующего исходника.
- Все обязательные навыки имеют самостоятельное доказательство **до** F1; F1 повторно наблюдает только необходимые для выбранной задачи действия, но всегда требует собственного применения результата.
- Для B3 самостоятельное решение стоит до передачи собственного материала; ранние учебные загрузки используют только безопасные фиктивные assets.
- Для B10 каждый зачет требует открытия/сопоставления реального основания; встроенная «самопроверка» ИИ и согласие второй модели не являются доказательством.
- Для каждой самостоятельной проверки задано наблюдаемое действие, критерий, непрохождение и пакет доказательств; «урок пройден» и «ИИ ответил хорошо» нигде не достаточны.
- Интерфейсная помощь допускается отдельно от содержательной: подсказка нужного приема во время уровня 3 переводит попытку в практику и требует новой проверочной ситуации.
- Сервисные маршруты не расширены сверх SM v1.0: B8 BACKUP ограничен подтвержденным изменением фона; B10 сервис-независим; платная функция не используется как спасение обязательного действия.
- Циклических учебных зависимостей не создано: ранние знакомства могут быть поддержанными, а самостоятельные проверки идут после предусмотренной практики. Возвраты рабочего цикла не трактуются как prerequisite-циклы.
- F1 соответствует D-F1 и LS §19: обоснованный отказ правильный и не штрафуется, но до завершенной задачи с применением F1 имеет статус «пока не завершена».
- Acceptance-тест сервисов, пилот, бета и проверка на 3–5 новичках **не объявлены проведенными**.

### 9.2. Что сознательно не произведено

Не созданы готовые тексты 21 урока, финальные тестовые вопросы, скриншоты интерфейсов, медиа и Stepik-экраны. Asset ID в §7 — спецификации будущих материалов. Это сохраняет границу этапа, заданную CA §31.

### 9.3. Оставшиеся внешние условия

Перед публичным выпуском по-прежнему нужны: ручная приемочная проверка PRIMARY/BACKUP на свежих бесплатных аккаунтах и обычном российском соединении; перепроверка регистрации, возраста, устройств, форматов и графического редактирования; пилот/бета на реальных новичках с наблюдением самостоятельных действий. Матрица покрытия не подменяет эти результаты.

## 10. Ограниченная следующая задача после утверждения Матрицы

Следующий производственный шаг: **создать проектные карточки 21 урока по LS/LT на основании этой Матрицы, без написания полного ученического текста**. Для каждого Lesson ID перенести из §4–7 результат, упражнения/check IDs, доказательства, prerequisites, PRIMARY/BACKUP, риски и Asset ID; затем прогнать Lesson Gate на уровне карточки. Массовое производство текстов, медиа и Stepik-шагов начинается только после проверки этих карточек.
