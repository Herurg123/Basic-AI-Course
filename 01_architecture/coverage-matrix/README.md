# Coverage matrix

Матрица связи: компетенция → модуль → урок → упражнение → проверка → самостоятельность → сервис → риск → источник. Нужна для поиска пробелов, зависимостей, ложных дублей и подмены навыка удачным ответом ИИ.

## Действующая версия

Канонический вход: [Полная Матрица покрытия v1.0](coverage-matrix-v1.0.md), утвержденная в `main`.

Для читаемого Git-diff Матрица v1.0 хранится как связанный комплект: индекс и контракт компетенций, педагогическая таблица 21 урока, операционная таблица, реестр самостоятельных проверок и реестр Asset ID с авторской валидацией. Индексный файл содержит ссылки на все части.

Матрица не является готовым текстом уроков или Stepik-экранами. Изменение одной части, создающее противоречие с другой, не считается допустимым к производству урока до исправления.

Следующий этап использует Матрицу как производственный контракт для проектных карточек всех 21 уроков; места самостоятельных проверок и архитектурные инварианты не переносятся ради удобства карточки.
