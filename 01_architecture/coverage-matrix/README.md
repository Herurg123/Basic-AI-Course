# Coverage matrix

Матрица связи: компетенция → модуль → урок → упражнение → проверка → самостоятельность → сервис → риск → источник. Нужна для поиска пробелов, зависимостей, ложных дублей и подмены навыка удачным ответом ИИ.

Канонический документ: [Полная Матрица покрытия v1.0](coverage-matrix-v1.0.md).

В v1.0 зафиксированы все 19 компетенций, 9 модулей и 21 Lesson ID утвержденной архитектуры, Exercise/Check/Asset ID, наблюдаемые доказательства, PRIMARY/BACKUP, риски и отдельный реестр самостоятельных проверок. Матрица не является готовым текстом уроков или Stepik-экранами.
