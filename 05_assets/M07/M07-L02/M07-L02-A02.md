# M07-L02-A02 — Авторская рубрика финальной работы

> **AUTHOR ONLY. Не выдавать ученику до завершения independent attempt.**
>
> Рубрика оценивает evidence, а не задаёт workflow. Действует D-2026-09-13-LEARNER-UX: отдельное заранее названное поле не требуется; post-action explanation может пояснять уже существующий natural trace.

| Измерение | PASS | FAIL / NOT PROVEN |
|---|---|---|
| Own new real task | задача принадлежит ученику, новая, посильная, безопасная | готовый кейс, копия примера, high-stakes или фактически чужая задача |
| Goal / fit criteria | до содержательной оценки существовал собственный понятный образ завершения; он поддерживается natural trace и при необходимости post-action пояснением | признаки результата впервые придуманы после работы и никак не поддерживаются ранним trace |
| Safe context/material | если материал или данные нужны, privacy-действие выполнено до передачи | privacy violation; post-hoc обезличивание |
| Human evaluation | ученик сам оценивал промежуточный результат и не делегировал пригодность модели | убедительный ответ принят автоматически |
| Refine when needed | если была реальная проблема, ученик сам выбрал разумную доработку или смену подхода | нужная правка подсказана; явная проблема проигнорирована |
| Verify when needed | существенное сопоставлено с реальным основанием; статус влияет на действие | AI self-check/second model/link-only; существенное применено как факт без основания |
| Independent next step | содержательные переходы выбирал ученик; допустима только technical help | автор вёл по шагам |
| Stop/switch | при непригодности ученик способен остановиться или сменить подход | небезопасное применение ради «закрытия» |
| Explain decisions | объяснение связано с реально наблюдаемыми решениями и может уточнять их смысл | post-action рассказ не поддерживается никаким наблюдаемым действием |
| Actual completion | исходная новая задача действительно завершена | работа остановилась на генерации или черновике |
| Actual application | есть безопасный наблюдаемый след конечного применения | «я бы применил», намерение, ответ только в чате |
| Temporal independence | ключевые решения поддерживаются natural trace, возникшим до раскрытия способной подсказать рубрики; не требуется отдельная формальная запись каждого критерия | ключевые действия существуют только в post-action рассказе либо появились после содержательной подсказки |

## Critical fail

F1 не засчитывается при privacy violation; high-stakes unsafe application; содержательно пошагово проведённой попытке; применении существенного неподтверждённого как факта; незавершённой задаче; отсутствии actual application.

## Adaptive rule

Не требовать file/search/image/calculation/second service, если они не нужны выбранной задаче. Отсутствие ненужного действия не является минусом.

Итоговый PASS возможен только когда все **применимые** измерения зачтены, а `Actual completion` и `Actual application` зачтены всегда.
