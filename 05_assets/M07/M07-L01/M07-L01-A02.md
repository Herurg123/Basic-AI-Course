# Памятка для связной работы

Это **не инструкция по шагам**. Не идите по пунктам сверху вниз и не пытайтесь обязательно использовать каждый.

Во время работы иногда полезно спросить себя:

- понимаю ли я, какой результат сейчас нужен;
- передаю ли только допустимую и нужную информацию;
- есть ли важное утверждение, которое стоит проверить перед применением;
- оказался ли пригодный результат там, где он действительно нужен, а не только в чате;
- если что-то изменилось или не получилось, какое из уже знакомых действий сейчас уместно.

В конкретной задаче часть этих вопросов может вообще не понадобиться.
