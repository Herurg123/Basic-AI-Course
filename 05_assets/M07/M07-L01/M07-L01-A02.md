# M07-L01-A02 — Общая памятка связной работы

Эта карточка **не является планом шагов**. Не идите по ней сверху вниз и не пытайтесь использовать каждый пункт.

В любой момент работы полезно держать в поле зрения несколько вещей:

- какой результат сейчас нужен и по чему вы поймёте, что он пригоден;
- передаёте ли вы только допустимую и действительно нужную информацию;
- есть ли в результате что-то существенное, чему нельзя доверять без основания;
- оказался ли пригодный результат там, где он реально нужен, а не только в ответе ИИ;
- если что-то пошло не так, какой из уже знакомых способов разумно выбрать теперь.

Для конкретной задачи часть этих вопросов может вообще не понадобиться.
