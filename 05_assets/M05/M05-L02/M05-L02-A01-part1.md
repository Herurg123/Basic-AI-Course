# Исходная картинка для первой публикации

Для публикации о **вечере настольных игр** нужна новая квадратная иллюстрация.

Известно:

- на изображении не должно быть реальных людей, логотипов или личных данных;
- должно быть сразу понятно, что тема связана с настольными играми;
- для первой публикации нужен **тёмный цветной фон**, чтобы карточка отделялась от светлой ленты;
- длинный текст на самой картинке не нужен.
