# M05-L02-A01 — часть 1. Новая визуальная задача

> Student-facing staged view одного Asset ID `M05-L02-A01`. Вторая часть открывается только после завершения E01/C01.

Для публикации о **вечере настольных игр** нужна новая квадратная иллюстрация.

Ограничения ситуации:

- изображение должно быть нейтральным и не содержать реальных людей, логотипов или личных данных;
- оно должно явно ассоциироваться с настольными играми;
- для первой публикации нужен **тёмный цветной фон**, чтобы карточка заметно отделялась от светлой ленты;
- длинный текст на самой картинке не нужен.

Остальные существенные требования и конкретное описание для ИИ сформулируйте сами.

Создайте изображение живым ИИ-сервисом и сохраните первую версию.
