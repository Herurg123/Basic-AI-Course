# M03-L02-A03 — другой интерфейс

**Статус:** `READY`  
**Логический Asset ID:** `M03-L02-A03`

У этого Asset ID два реальных безопасных PNG-варианта. Ученик получает тот, который показывает **другой** интерфейс относительно основной попытки:

- [`M03-L02-A03.png`](M03-L02-A03.png) — реальный GigaChat; используется, если `E01` выполнялся в Алисе AI;
- [`M03-L02-A03-alice.png`](M03-L02-A03-alice.png) — реальная Алиса AI; используется, если `E01` выполнялся через GigaChat.

Новый Asset ID не создаётся. Разветвление нужно только затем, чтобы обязательное сравнение никогда не превращалось в сравнение GigaChat с самим собой или Алисы с самой собой.

Asset используется для `M03-L02-E02 / C02`: ученик должен распознать переносимый принцип работы в другом интерфейсе, а не знание бренда или расположения конкретной кнопки. Вход во второй сервис и дополнительный аккаунт для C02 не требуются.

## Вариант GigaChat

`M03-L02-A03.png` — ранее подготовленный реальный безопасный screenshot авторизованного GigaChat web, утверждённого BACKUP. Для обычного маршрута урока основной интерфейс ученика — Алиса AI.

На изображении сохранён нейтральный учебный текстовый диалог и достаточно элементов интерфейса для распознавания другого интерфейса. Снимок ранее прошёл независимую проверку проекта.

## Вариант Алисы AI

`M03-L02-A03-alice.png` подготовлен из **реального снимка Алисы AI, предоставленного владельцем проекта 14.09.2026**.

В исходном снимке слева была видна пользовательская история чатов. Репозиторий сохранил только повреждённые производные этого реального изображения. В B3 канонический PNG восстановлен **только из декодируемых пикселей ранней производной**: tolerant decode повреждённого PNG → обычное lossless PNG-кодирование. Новые элементы интерфейса, текст, кнопки, бренд или пользовательские данные не генерировались и не дорисовывались. Источник пикселей остаётся тем же реальным снимком владельца; визуальная достаточность восстановленного кадра отдельно проверяется HUMAN VISUAL перед публикацией.

Исходная учебная обрезка ранее проходила проверку на отсутствие имени, email, телефона, QR, токенов, account ID и названий личной истории чатов. После B3-восстановления пикселей этот вывод **не переносится автоматически**: видимый восстановленный кадр и обе опубликованные ветки повторно проверяются на HUMAN VISUAL/read-back gate.

## Общие требования к двум вариантам

1. **Реальный интерфейс:** не использовать сгенерированный макет.
2. **Нейтральный контент:** без персональных и чувствительных данных.
3. **Достаточная различимость:** должно быть видно, что это другой ИИ-интерфейс; бренд не является предметом ответа ученика.
4. **Цель задания:** увидеть переносимое действие текстового диалога, а не сравнивать расположение кнопок.
5. **Проверка перед публикацией:** открыть ученические ссылки из собранного Stepik-маршрута для обеих веток и убедиться, что после Алисы действительно показывается GigaChat, а после GigaChat — Алиса AI.
