# M03-L02-A03 — второй интерфейс

**Статус:** `READY`  
**Финальный файл:** [`M03-L02-A03.png`](M03-L02-A03.png)

Реальный безопасный PNG второго подходящего ИИ-интерфейса добавлен в репозиторий и ранее был предоставлен независимому аудитору M02–M03, который его принял.

Asset используется для `M03-L02-E02 / C02`: ученик должен распознать переносимый принцип работы в другом интерфейсе, а не знание бренда или расположения конкретной кнопки.

## Требования, по которым asset был подготовлен

1. **Сервис:** авторизованный GigaChat web, то есть утверждённый BACKUP. Для обычного маршрута урока основной интерфейс ученика — Алиса; регистрация ученика во втором сервисе для `C02` не требуется.
2. **Экран:** отдельный нейтральный учебный чат без личной истории.
3. **На изображении должно быть достаточно видно:**
   - область текстового диалога;
   - первое нейтральное сообщение пользователя;
   - первый ответ;
   - следующее конкретное сообщение пользователя;
   - изменённый ответ;
   - достаточно элементов интерфейса, чтобы было видно отличие от основного сервиса, без необходимости делать бренд предметом задания.
4. **Не допускаются:** имя, email, телефон, avatar, QR, cookies, токены, идентификаторы аккаунта, боковая панель с личной историей, персональные запросы и иные реальные пользовательские данные.
5. **Формат:** PNG. `M03-L02-A03.png` относится к тому же Asset ID и не создаёт новый Asset ID.

## Ограничение маршрута

Если самостоятельная попытка `M03-L02-E01` проходится через GigaChat как BACKUP, GigaChat-скриншот не является переносом на другой интерфейс. Для такой ветки нужен безопасный снимок Алисы под тем же Asset ID либо `C02` выполняется в варианте, который действительно показывает другой интерфейс.
