# M00-L01-A01 — карточка безопасного первого ввода

Все примеры ниже учебные и нейтральные. Выберите один или придумайте похожий.

1. «Составь список из трех вещей, которые стоит взять на короткую учебную встречу.»
2. «Объясни простыми словами, зачем делать резервную копию файла.»
3. «Предложи два нейтральных названия для учебной заметки о планировании.»

Перед отправкой проверьте: в запросе нет реальных имен, телефонов, адресов, документов, паролей, медицинских сведений, банковских данных или рабочих секретов.

Для второй попытки выберите один простой критерий результата: длина, количество пунктов, понятность или формат.
