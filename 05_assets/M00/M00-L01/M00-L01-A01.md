# Безопасные примеры для первого запроса

Все примеры ниже вымышлены и не требуют личных данных. Выберите один или придумайте похожую небольшую задачу.

1. «Составь список из трёх вещей, которые стоит взять на короткую учебную встречу.»
2. «Объясни простыми словами, зачем делать резервную копию файла.»
3. «Предложи два нейтральных названия для заметки о планировании.»

Перед отправкой быстро спросите себя: **есть ли в запросе сведения, без которых задача спокойно решается?** Если есть, уберите их.

Для этого упражнения не нужны реальные имена, телефоны, адреса, документы, пароли, медицинские сведения, банковские данные или рабочие секреты.
