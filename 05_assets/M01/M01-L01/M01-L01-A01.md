# M01-L01-A01 — безопасная мини-задача

Составьте короткое напоминание для участника вымышленной учебной встречи «Практика».

Нужно сообщить:

- начало в 18:30;
- кабинет 204.

**Критерий:** итоговый текст должен состоять не более чем из двух предложений и содержать и время, и номер кабинета.

После получения ответа сравните его только с этим критерием.
