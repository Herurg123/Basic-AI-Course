# Учебная ситуация: внешний факт

Это заранее подготовленный пример ответа ИИ. **Не считайте его проверенным фактом.**

Вы помогаете знакомому сделать короткую памятку для человека, который недавно начал пользоваться компьютером с Windows.

ИИ предложил добавить строку:

> «В Firefox сочетание `Ctrl + Shift + T` возвращает последнюю закрытую вкладку. Эту команду можно смело включить в памятку как способ восстановить случайно закрытую вкладку».

В памятке мало места, поэтому ошибочная строка будет мешать, а правильная действительно пригодится.
