# M04-L01-A02 — авторский ключ проверки

> Только для автора/проверяющего. Не выдавать ученику как готовый ответ до `M04-L01-C01`.

Основание: `M04-L01-A01.txt`.

## Примеры корректных сопоставлений

| Возможное утверждение ответа | Фрагмент основания | Ожидаемый статус |
|---|---|---|
| «Встреча идёт 18 октября с 14:00 до 16:00» | «Дата: суббота, 18 октября» + «Время для посетителей: с 14:00 до 16:00» | подтверждено |
| «Можно принести не больше пяти книг» | «до 5 книг на одного участника» | подтверждено |
| «Регистрация заранее не нужна» | «предварительная регистрация не требуется» | подтверждено |
| «Организаторы выдадут пакет для книг» | «пакеты для книг организаторы не выдают» | не подтверждено / противоречит исходнику |
| «У библиотеки есть парковка» | в конце прямо указано, что информации о парковке нет | данных недостаточно |
| «Все учебники запрещены» | запрещены только «учебники старше 10 лет» | частично / формулировка ответа слишком широкая |

## Правило проверки

Зачёт не зависит от совпадения с одной из строк таблицы. Ученик может выбрать другое существенное утверждение, если он сам открывает исходник, находит относящийся к нему фрагмент и логично присваивает статус.

Если фрагмент подсказывает автор до выбора ученика, попытка остаётся практикой и не доказывает самостоятельный поиск основания.
